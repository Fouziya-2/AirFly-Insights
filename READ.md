# AirFly_Insights

# ✈️ AirFly Smart Airline Insights Dashboard

## 📌 Project Overview
This project analyzes airline operations data to understand patterns into:
- Flight delays
- Airport traffic
- Flight cancellations
- Seasonal trends

The goal is to derive insights and present them through visualizations and an interactive dashboard.


## 🎯 Objectives
- Analyze airline performance data
- Identify key delay factors
- Understand airport traffic patterns
- Visualize trends using graphs
- Build an interactive Streamlit dashboard

## 🖥️ Milestone 3: Streamlit Dashboard
An interactive dashboard was developed using Streamlit.
This dashboard provides an interactive analysis of airline flight data, focusing on delays, cancellations, busiest routes, airport traffic, and flight trends. It includes dynamic filters, KPI metrics, geographical mapping, and multiple visualizations to help users explore patterns and derive meaningful insights for better decision-making.

### Features:
- Dataset preview
- Airport traffic analysis
- Delay analysis by cause
- Seasonal trends visualization
- Flight cancellation insights


## 📊 Key Insights
- Major airports handle high traffic leading to congestion
- Carrier and weather delays are common
- Delay patterns vary across seasons
- Flight cancellations are influenced by operational and environmental factors
